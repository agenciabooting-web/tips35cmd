Tips35cmd Publisher

Ferramenta pessoal de publicação do criador @tips35cmd · Personal publishing tool of the creator @tips35cmd

Tips35cmd Publisher is a private, single-user desktop tool. It uploads short educational videos about Windows commands, produced and reviewed by the account owner, to the owner's own TikTok account (@tips35cmd) through the official TikTok Content Posting API. It is not offered to other users.

Privacy Policy / Política de Privacidade

Last updated: November 17, 2026

  • Data accessed: after the account owner authorizes the app with TikTok Login Kit, the tool stores an access token, a refresh token and the TikTok open_id, and reads the account's display name and the posting options returned by the creator info endpoint.
  • Purpose: only to upload the owner's own videos and show the posting status.
  • Storage: tokens are kept only on the owner's personal computer, in a local folder that is never shared or uploaded. No server, database, analytics or advertising is used.
  • Sharing: no data is sold or shared with third parties. Data goes only to TikTok's own API.
  • Deletion: the owner can revoke access at any time in TikTok → Settings → Security → Apps and services, and the local token file is deleted.
  • Contact: through the TikTok account @tips35cmd.
